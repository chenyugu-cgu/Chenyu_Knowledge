# Electromagnetism

Electromagnetism describes electric and magnetic fields and their interaction with charge and current. Unified by Maxwell's equations, it explains electricity, magnetism, light, and the operation of nearly every electrical device — and is essential to MRI, bioelectricity, and antenna/sensor design.

## The Field Picture

Charges create **electric fields** \\(\mathbf{E}\\); moving charges (currents) create **magnetic fields** \\(\mathbf{B}\\). Fields exert forces via the **Lorentz force**:
\\[
\mathbf{F} = q(\mathbf{E} + \mathbf{v}\times\mathbf{B}).
\\]
