# Biomedical Engineering

Biomedical engineering applies engineering principles to medicine and biology — diagnosing disease, restoring function, and improving health. It is inherently interdisciplinary, drawing on every other section of this book.

## Major Areas

- **Medical imaging** — seeing inside the body non-invasively. See [Medical Imaging](imaging.md).
- **Biomaterials** — materials that work safely inside the body. See [Biomaterials](biomaterials.md).
- **Rehabilitation engineering** — restoring lost function. See [Rehabilitation Devices](rehab.md).
- **Biomechanics** — mechanics of living systems. See [Biomechanics](../biomechanics/README.md).
- **Biosignal processing, instrumentation, tissue engineering, and computational medicine.**

## Cross-Cutting Themes

- **Biocompatibility** — every device must coexist with living tissue without harm.
- **Safety and regulation** — medical devices face rigorous standards (FDA, ISO 13485, IEC 60601).
- **Signal and image processing** — physiological data is noisy and demands careful [DSP](../../eng/electrical/signal-processing.md).
- **Modeling** — physiological systems are modeled with the same [control](../../eng/control/README.md) and [dynamics](../../eng/dynamics/README.md) tools as machines.
