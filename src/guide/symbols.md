# Mathematical Symbols

This section provides a structured overview of the most common mathematical symbols used throughout this book. The symbols follow conventional usage in mathematics, engineering, and physics, and consistency is maintained across the book to aid clarity and understanding.

## General Symbols

| Symbol         | Meaning             |
| -------------- | ------------------- |
| \\(=\\)        | Equals              |
| \\(\\approx\\) | Approximately equal |
| \\(\\infty\\)  | Infinity            |

## Set Theory

| Symbol           | Meaning            |
| ---------------- | ------------------ |
| \\(\\in\\)       | Element of         |
| \\(\\subseteq\\) | Subset or equal to |
| \\(\\cup\\)      | Union              |
| \\(\\cap\\)      | Intersection       |

## Logic

| Symbol         | Meaning      |
| -------------- | ------------ |
| \\(\\forall\\) | For all      |
| \\(\\exists\\) | There exists |
| \\(\\neg\\)    | Not          |
| \\(\\land\\)   | And          |
| \\(\\lor\\)    | Or           |

## Calculus

| Symbol              | Meaning                            |
| ------------------- | ---------------------------------- |
| \\(\\frac{d}{dx}\\) | Derivative with respect to \\(x\\) |
| \\(\\partial\\)     | Partial derivative                 |
| \\(\\nabla\\)       | Gradient operator                  |
| \\(\\int\\)         | Integral                           |
| \\(\\sum\\)         | Summation                          |
| \\(\\prod\\)        | Product                            |

## Linear Algebra

| Symbol                   | Meaning           |
| ------------------------ | ----------------- |
| \\(\\mathbf{I}\\)        | Identity matrix   |
| \\(\\det\\)              | Determinant       |
| \\(\\operatorname{tr}\\) | Trace of a matrix |
| \\(\\otimes\\)           | Tensor product    |

## Probability & Statistics

| Symbol                    | Meaning                         |
| ------------------------- | ------------------------------- |
| \\(\\mathbb{P}\\)         | Probability                     |
| \\(\\mathbb{E}\\)         | Expectation (mean)              |
| \\(\\operatorname{Var}\\) | Variance                        |
| \\(\\sigma^2\\)           | Variance (alternative notation) |
| \\(\\mu\\)                | Mean                            |
