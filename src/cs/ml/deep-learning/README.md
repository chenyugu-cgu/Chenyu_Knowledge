# Deep Learning

Deep learning builds models from stacked, differentiable layers trained by gradient descent. The chapters follow the course in spirit: linear classifiers and gradient descent, backpropagation and training, convolutional networks, dense prediction and detection, recurrent networks, attention and transformers, deep reinforcement learning and RLHF, scaling, 3D scene representations, generative models, and the fairness and alignment questions.

This section follows the graduate course CS 7643 Deep Learning (Georgia Tech). For a one-page overview, see [Deep Learning](../deep-learning.md). The shallow-network basics are in [Neural Networks](../neural-networks.md), and the hand-worked version of backpropagation is in [Backpropagation and Network Architectures](../../ai/backpropagation.md).
