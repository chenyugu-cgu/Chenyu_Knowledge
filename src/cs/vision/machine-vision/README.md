# Machine Vision

Machine vision is computer vision with an engineering purpose: measure a part, guide a robot, inspect a weld, sort fruit by color. Its methods are chosen for reliability and accuracy under controlled conditions. It covers designed lighting, calibrated cameras, explicit geometric models and well-understood image operators, with learned models where hand-designed features fall short.

This subsection follows the graduate course *Machine Vision* (Georgia Tech ME 6406). The course moves from how an image is formed, through the classical operators that extract edges, lines and shapes, to calibration and 3-D measurement, color and neural networks.
