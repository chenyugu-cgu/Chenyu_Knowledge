# Notation Index

The conventions used throughout this book. See also [Notation and Conventions](../guide/notation.md) and [Mathematical Symbols](../guide/symbols.md).

## General

| Symbol | Meaning |
|---|---|
| \\(x,\ y,\ z\\) | scalar variables |
| \\(\mathbf{x},\ \mathbf{v}\\) | vectors (bold lowercase) |
| \\(A,\ M\\) | matrices (uppercase) |
| \\(\hat{x}\\) | estimate of \\(x\\) |
| \\(\bar{x}\\) | mean / average of \\(x\\) |
| \\(\dot{x},\ \ddot{x}\\) | first, second time derivatives |
| \\(x^*\\) | optimal value / complex conjugate (by context) |
| \\(\mathbb{R},\ \mathbb{C},\ \mathbb{Z}\\) | reals, complex numbers, integers |

## Calculus and Analysis

| Symbol | Meaning |
|---|---|
| \\(f'(x),\ \frac{df}{dx}\\) | derivative |
| \\(\frac{\partial f}{\partial x}\\) | partial derivative |
| \\(\nabla f\\) | gradient |
| \\(\nabla\cdot\mathbf{F}\\) | divergence |
| \\(\nabla\times\mathbf{F}\\) | curl |
| \\(\int,\ \oint\\) | integral, closed-contour integral |
| \\(\lim,\ \sum,\ \prod\\) | limit, sum, product |

## Probability and Statistics

| Symbol | Meaning |
|---|---|
| \\(P(A)\\) | probability of event \\(A\\) |
| \\(p(x),\ f(x)\\) | probability mass / density |
| \\(\mathbb{E}[X]\\) | expectation |
| \\(\operatorname{Var}(X),\ \sigma^2\\) | variance |
| \\(\mathcal{N}(\mu,\sigma^2)\\) | normal distribution |
| \\(X \sim D\\) | \\(X\\) is distributed as \\(D\\) |

## Signals and Systems

| Symbol | Meaning |
|---|---|
| \\(x(t),\ x[n]\\) | continuous-, discrete-time signal |
| \\(\delta,\ u\\) | impulse, unit step |
| \\(*\\) | convolution |
| \\(X(\omega),\ X(s),\ X(z)\\) | Fourier, Laplace, Z transforms |
| \\(h(t),\ H(s)\\) | impulse response, transfer function |
| \\(\omega,\ f\\) | angular frequency (rad/s), frequency (Hz) |

## Mechanics and Fields

| Symbol | Meaning |
|---|---|
| \\(\mathbf{F},\ \mathbf{M}\\) | force, moment |
| \\(\sigma,\ \tau\\) | normal, shear stress |
| \\(\varepsilon,\ \gamma\\) | normal, shear strain |
| \\(E,\ G,\ \nu\\) | Young's, shear modulus, Poisson's ratio |
| \\(\zeta,\ \omega_n\\) | damping ratio, natural frequency |

## Set, Logic, and Operators

| Symbol | Meaning |
|---|---|
| \\(\in,\ \subset,\ \cup,\ \cap\\) | membership, subset, union, intersection |
| \\(\forall,\ \exists\\) | for all, there exists |
| \\(\Rightarrow,\ \Leftrightarrow\\) | implies, if and only if |
| \\(\approx,\ \propto,\ \equiv\\) | approximately, proportional to, defined as |
| \\(\lVert\cdot\rVert,\ \lvert\cdot\rvert\\) | norm, absolute value |
