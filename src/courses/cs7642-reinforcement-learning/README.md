# Reinforcement Learning

Reinforcement learning trains an agent to act in an environment from reward alone. The chapters start with the Markov decision process framework and the Bellman equations, then cover learning from experience and its convergence. Reward design, exploration and generalization come next. The subsection then turns to partially observable settings and options, and ends with multi-agent games, coordination, coaching and human input.

This section follows the graduate course CS 7642 Reinforcement Learning (Georgia Tech). For a one-page overview, see Reinforcement Learning. The first treatment of Markov decision processes and value iteration is in [Markov Decision Processes](../cs3600-cs6601-artificial-intelligence/mdps.md).
