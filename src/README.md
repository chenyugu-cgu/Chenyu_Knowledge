# Introduction

Welcome to **Chenyu's Knowledge Base** — a personal, cookbook-style reference covering the mathematics, engineering sciences, and computational methods gathered across a career of study and practice.

## What This Book Is

This is a **cookbook of scientific methods and engineering principles**: concise, practical, and grounded in rigorous theory. It exists so that knowledge encountered once — in a course, a project, or a paper — is not lost, but preserved in a form that is quick to revisit and ready to apply. Read the full motivation in the [Preface](preface.md).

## How It Is Organized

The book builds from foundations to applications:

1. **[How to Use This Book](guide/purpose.md)** — purpose, recipe structure, notation, symbols, and units.
2. **[Mathematical and Computational Foundations](math/calculus/README.md)** — calculus, linear algebra, probability, numerical methods.
3. **[Signals and Systems](signals/fundamentals.md)** — the bridge between theory and engineering.
4. **[Core Engineering Sciences](eng/statics/README.md)** — statics, dynamics, materials, control, thermodynamics, fluids, electronics.
5. **[Advanced Computational Science](cs/optimization/README.md)** — optimization, machine learning, data science.
6. **[Applied Engineering Domains](app/robotics/README.md)** — robotics, biomechanics, materials science, biomedical engineering.
7. **[Cookbook Recipes](cookbook/examples/README.md)** — complete worked examples with runnable code.
8. **[Appendices](appendix/tables.md)** — tables, constants, formula and notation references, bibliography.

## How to Read It

- **Looking something up?** Jump straight to the chapter or the [Formula Reference](appendix/formulas.md).
- **Learning a topic?** Read the section README, then the chapters, then the matching [recipes](cookbook/examples/README.md).
- **Want to run the code?** Many recipes include Rust snippets that execute in the browser (click ▶); Python and MATLAB examples are ready to copy.

## Conventions

Mathematics is rendered with MathJax using `\\(...\\)` for inline and `\\[...\\]` for display expressions. Each recipe follows the standardized format described in [Structure of a Recipe](guide/structure.md).

> This is a living document — it grows as new knowledge is learned and old knowledge is revisited.
